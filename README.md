# TOCFL A1–B1 Study Website

A static, Vietnamese-language Traditional Chinese learning website.

## Publish with GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. Open **Actions → Deploy TOCFL study website**.
4. If the workflow did not run after Pages was enabled, choose **Run workflow** on the `main` branch.

The public site URL will be:
`https://vule68682-creator.github.io/nvu008/`

The site is a static HTML app. No server or installation is needed. Study progress is stored in the current browser on each device and is not automatically synchronized between devices.
